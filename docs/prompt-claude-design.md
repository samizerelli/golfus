# Prompt pour Claude Design

```
Refais le design de mon app GolfUs : https://golfus-app.netlify.app (code : https://github.com/samizerelli/golfus).

GolfUs sert à organiser une partie de golf entre amis : on appuie sur « New game », on choisit un golf, on invite ses amis, ils répondent « Rejoindre » ou « Décliner ».

Je veux un design simple, moderne et facile à utiliser sur téléphone, en vert golf et blanc, avec un mode sombre. Garde toutes les fonctionnalités, ne rajoute rien.

Quand une info est inconnue (prix, horaires), affiche « Non communiqué », n'invente jamais rien.
```
